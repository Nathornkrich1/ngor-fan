# QR ง้อแฟน 💗

ไฟล์ `index.html` คือหน้าเว็บง้อแฟน และ `apology-melody.wav` คือเพลงสั้น ๆ ที่สร้างขึ้นใหม่สำหรับหน้าเว็บ

## วิธีทำให้ QR ใช้งานได้จริง
1. สร้าง GitHub repository ใหม่ เช่น `ngor-fan`
2. อัปโหลด `index.html` และ `apology-melody.wav`
3. เปิด Settings → Pages → Deploy from branch → เลือก `main` และ `/ (root)`
4. เมื่อได้ URL เช่น `https://USERNAME.github.io/ngor-fan/` ให้ใช้ URL นั้นสร้าง QR Code

หมายเหตุ: QR ในภาพตัวอย่างไม่ใช่ QR ของเว็บจริง เพราะต้องใช้ URL หลังจากนำเว็บขึ้นโฮสต์ก่อน
